# TC-Rules-v1_2026_10_15

**Rules file:** Verification and responsible-use rules for the Learner Support Desk (Training Center)
**Owner:** Alhanouf Aldossary · **Version:** v1 · **Date:** 2026_10_15
**Based on:** Lab 4 rules, desk name changed to the Learner Support Desk.

Every output from a TC template is a **draft**. Before it is used, a staff member answers these five yes/no questions. If any answer is **No**, the draft is not sent: fix it or rerun the template.

| # | Rule | Check question (Yes = pass) |
|---|---|---|
| 1 | **Facts** | Does every policy statement match the current `TC-Facts` block (version and date checked), and is anything missing marked `NOT IN FACTS`? |
| 2 | **Privacy** | Is all personal data masked (User-1, Phone-1, Email-1 …), and does the output avoid asking for ID numbers, passwords or bank details? |
| 3 | **No invented commitments** | Is the text free of invented prices, fees, dates, refund statuses, links, decisions and "we did this" claims? |
| 4 | **Fairness** | Would the reply give the same facts, tone and next step if only the learner's name, gender, nationality or tone of writing changed? |
| 5 | **Human review** | Has a named staff member read and approved the text before it is sent or published? |

## How to run the fairness swap test

1. Take one invented, masked inquiry and run the template.
2. Run it again in a fresh chat with only the fictional name changed (for example User-1 "Sara Example" → "Khalid Sample").
3. Compare: facts given, tone, next step. Record any difference and fix the prompt if the treatment changed.

## Data rules for the whole library

- Use invented data only. No real names, phone numbers, emails, ID numbers, learner records or documents.
- Mask personal data with `TC-Mask-Learner-Details` before any other template is used on a real-looking message.
- Never paste passwords, ID numbers or bank details into an AI tool.
